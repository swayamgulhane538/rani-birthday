## 🚀 4. How to Deploy Online for Free (Share Link with Rani)

You can host this for **100% free** in less than 2 minutes:

### Option A: Netlify Drop (Easiest - 60 Seconds, No Sign-up/Command Line Needed)
1. Go to [https://app.netlify.com/drop](https://app.netlify.com/drop) in your browser.
2. Drag and drop the whole `rani-birthday-gift` folder into the Netlify Drop area.
3. In 10 seconds, Netlify will generate a live URL (e.g., `https://rani-birthday-gift.netlify.app`).
4. Copy the link and send it to Rani on WhatsApp! 💖

### Option B: Vercel
1. Go to [https://vercel.com](https://vercel.com) and log in.
2. Click **"Add New Project"** -> Drag and drop the folder or connect your GitHub repository.
3. Click **Deploy**. Your custom link will be live immediately.

### Option C: GitHub Pages
1. Create a new GitHub repository named `rani-birthday-gift`.
2. Upload all files (`index.html`, `style.css`, `script.js`, `song.mp3`, and the `images/` folder).
3. Go to **Settings** -> **Pages** -> Select `main` branch -> Click **Save**.
4. Your website will be live at `https://<your-username>.github.io/rani-birthday-gift/`.
